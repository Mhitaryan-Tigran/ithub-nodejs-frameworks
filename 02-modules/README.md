# Модульная система, npm и зависимости

`npm init -y`, зависимости `lodash`, `dotenv`, dev-зависимость `nodemon`, собственный CommonJS-модуль `src/utils/math.js` (`add`, `multiply`, `average`), конфигурация из `.env`, скрипты `start` и `dev`.

```
npm install
cp .env.example .env
npm run dev
```

Вывод `npm run dev` — [output.txt](output.txt).
